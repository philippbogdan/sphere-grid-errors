# Data guide

The nine JSONL files in `evidence/` preserve the original bytes, including record metadata. `manifest.json` gives their hashes and counts. `claims.json` binds each headline to exact record selectors, source fields, numerators and denominators. Run `python3 -S scripts/reproduce.py` from the repository root to check them.

| File | Content | Reference |
|---|---|---|
| `relaxation.csv` | All 12 archived configurations at days 1, 3, 5, 7 and 10 | T85, 45 s step, also the correction target |
| `resolution.csv` | Nine day-14 endpoints, point counts, timesteps and ratios | T213, 22.5 s step |
| `context.csv` | Early and late main/TRSK/spectral series, plus the icosahedral comparison | T213, 22.5 s step |
| `restart.csv` | Every restart observation, elapsed time and available latitude bands | T213, 22.5 s step |
| `twins.csv` | Three perturbation histories, including the actual day-7 initial condition | Difference between paired solver runs |
| `visual-runs.json` | Checked summary values for the separate three-run day-14 extension | T85 full-precision scores; T213 scores from the saved fields |
| `field-metrics.csv` | 3,042 global, regional and pair-consistency measurements | Explicit reference on every row |
| `field-assets.json` | Local field-pack filenames, byte sizes and SHA-256 hashes | Regenerated under `build/fields/`; no download URLs |

The derived archived tables use round-trip float precision. Empty CSV cells mean a quantity was not recorded for that row, such as latitude-band errors outside the three-day restart endpoint. `computed_height_sites` counts main-scheme copies, TRSK cells or spectral grid sites; it does not equate work or degrees of freedom. `record_npts` preserves the original field where its interpretation differs. `velocity_edges` makes the TRSK staggering explicit.

The main endpoint in `resolution.csv` comes from `accuracy_main_ref.jsonl`. Its history in `context.csv` comes from `tc6_series.jsonl`; their slightly different day-14 values are retained, not overwritten to force agreement. The public solver's time-series and endpoint runs need not have identical step segmentation.

`mpas_ref.jsonl` contains scores from the public solver's own TRSK implementation, not an MPAS executable. The other records retain sharpness, filter sensitivity and alternative-reference checks even when they are not part of a headline. Original metadata fields are archival identifiers; the public dependency revision is specified separately in the manifest.

The reference called T85 in the intervention uses 45 s steps. The T85 resolution comparator uses 450 s steps. T213 and T341 reference-sensitivity records are separate comparisons, not confidence intervals. See [METHOD.md](../docs/METHOD.md) for all definitions and limitations.

[validation.json](validation.json) retains pair, snapshot and derivative checks; [field-runs/](field-runs/) contains the three original run sidecars. The field-metrics CSV uses ten significant digits, so its T213 endpoint scores are field-derived values, not full-precision solver endpoints. The renderer's independent reconstruction and its numerical checks are in [figures/manifest.json](../figures/manifest.json).

The six large NPZ files total about 114 MB and are not bundled or hosted. [REPRODUCE.md](../REPRODUCE.md) regenerates them locally. Their hashes identify the exact fields used here; compression or numerical-library differences can change regenerated bytes.
